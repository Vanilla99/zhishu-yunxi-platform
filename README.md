# 智鼠云析前端演示平台

智鼠云析是一个面向小鼠行为实验、超声波分析与药物助研场景的前端演示平台。当前版本不接入真实后端，重点用于产品展示、流程讲解和视觉验证。

## 本地运行

```bash
npm install
npm run dev -- --port 5174 --strictPort
```

访问地址：

```text
http://localhost:5174/
```

如果 `5174` 已被占用，可换成其他空闲端口。

## 推荐演示路径

1. 从产品首页进入平台，先展示品牌首屏、科研主视觉和核心能力。
2. 进入数据驾驶舱，说明累计实验、视频时长、超声波样本、分析任务和报告数量，并展示运行态摘要与最近任务队列。
3. 在重点实验列表选择实验，进入实验样例管理查看实验详情。
4. 在实验样例管理页使用“新建 / 导入样例”，载入演示文件并生成一条新的待分析实验记录。
5. 从实验详情发起智能分析，展示样例实验、任务类型、文件接入和任务队列。
6. 点击“开始智能分析”，等待进度完成，展示数据校验、视频帧读取、目标检测、轨迹跟踪、行为识别、超声波分析、多模态融合和报告草稿阶段。
7. 选择“预览报告草稿”，进入报告中心展示正式报告详情。
8. 在报告中心演示“打印/导出 PDF”“下载报告”“查看实验详情”“重新生成”。
9. 最后进入合作试点申请页，填写申请表单并展示提交成功反馈。
10. 查看“试点线索跟进”，说明申请已进入运营视角，包含优先级、状态和下一步动作。

## 主要文件

- `src/App.tsx`：页面结构、导航、演示路径和主要交互。
- `src/data/platformData.ts`：集中管理实验、图表、报告、申请页等演示数据。
- `src/data/mockService.ts`：模拟实验导入、分析任务创建、报告生成和合作线索创建。
- `src/components/ui.tsx`：按钮、面板、状态标签、弹窗、进度条等复用组件。
- `src/assets/hero-lab.png`：首页科研主视觉。
- `src/styles.css`：全局样式、表格样式与报告打印样式。
